# راهنمای فارسی پنل دانش‌آموز و سرپرست

45 صفحه با تصویر واقعی رابط فارسی برنامه و شماره‌گذاری دکمه‌ها.

- PDF: `planner-student-guardian-fa.pdf`
- PowerPoint: `planner-student-guardian-fa.pptx`
- نسخهٔ HTML مستقل: `planner-student-guardian-fa.html`

## محدودهٔ نمایش

نام‌ها، برنامه‌ها و نتیجه‌ها نمایشی و محلی هستند. ارسال میان دو حساب واقعی، دریافت QR از سرور، هوش مصنوعی، پخش واقعی ویدئو و بارگذاری/حذف واقعی عکس تکلیف آزمایش نشده‌اند. عملکرد این موارد از کد برنامه توضیح داده شده است. عددهای نارنجی افزوده‌های راهنما هستند، نه دکمهٔ خود برنامه. در PDF نوشتهٔ فارسی شکل‌دهی و قلم آن در فایل جاسازی شده است. پاورپوینت تصویرهای جاسازی‌شده و توضیح‌های راست‌به‌چپ دارد.
