# Personal Planner

A calm, local-first planner for the day, the week, the month, and the days ahead — tasks, habits, goals, and notes in one place.

Planner data stays in this browser (`localStorage`). Use **Export** in the sidebar if you want a backup file. There is no account and no server database.

```bash
npm install
npm run dev
```

Other scripts: `npm run typecheck`, `npm test`, `npm run build`.
